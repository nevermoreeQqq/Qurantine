# Карантин 6.0.4 — исправление запуска

Исправлена установка на Mac после блокировки первого запуска в 6.0.3.
Причина подтверждена на macOS 12.7.6 Intel: AppleSystemPolicy завершала
скачанное приложение до появления лаунчера. Файлы и локальная подпись были целыми.

- В DMG добавлен **Install-Quarantine.command**: проверяет подпись и архитектуру,
  разрешает первый запуск только этой Quarantine, проверяет лаунчер и вход в игру,
  затем устанавливает приложение. Предыдущая установка сохраняется как резервная копия.
- Проверка выпуска на Mac теперь включает установку из DMG со скачанной меткой quarantine.
- В настольные сборки включены модули web/platform, используемые встроенной игрой.
- Сохранены новый лаунчер, HUD «Графит», кооператив и исправления коллизий из 6.0.3.

## Скачать и установить

**Mac Intel:** Quarantine-6.0.4-macOS-x64.dmg.
**Mac Apple Silicon:** Quarantine-6.0.4-macOS-arm64.dmg.
Откройте DMG, закройте старую игру и запустите **Install-Quarantine.command** внутри образа.
При запросе macOS откройте установщик через правую кнопку → Открыть.
При блокировке скрипта используйте «Открыть всё равно» в настройках безопасности macOS.
Перетаскивание только значка приложения не выполняет исправление первого запуска.

Приложение имеет локальную подпись целостности, но пока не заверено Apple.
Установщик применяет разрешение только к Quarantine; системная защита не отключается.

**Windows:** Quarantine-Setup-6.0.4.exe; закройте игру и установите поверх предыдущей версии.
**Веб:** Quarantine-6.0.4-YandexGames.zip.
**Пакет игры:** Quarantine-Game-6.0.4.qtg. Для исправления установки на Mac требуется DMG,
пакет .qtg не заменяет настольную оболочку.

Репозиторий закрытый — для скачивания нужен GitHub-аккаунт с доступом.
