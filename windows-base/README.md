# Исходная Windows-база 6.0.0

`Quarantine-6.0.0-Windows-Source.zip` содержит оригинальные исходники из предоставленного архива `2dAk.zip`, без изменений для Mac. Удалены только устанавливаемые зависимости `node_modules`, готовые сборки `release` и диагностические артефакты. Код, ассеты и подписанные обновления сохранены байт в байт.

Основной проект в корне репозитория основан на этой версии и поддерживает Windows (`npm run build:win`), Intel Mac (`npm run build:mac:intel`) и Apple Silicon (`npm run build:mac:silicon`).
