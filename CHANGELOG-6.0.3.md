# Карантин 6.0.3 — новый лаунчер

Этот выпуск включает игру и новое оформление лаунчера в одном установщике.

- Новый экран лаунчера с иллюстрацией города, разделами «Обзор», «Версии игры» и «Новости».
- Настройки памяти, музыки и звуков; оригинальная музыка «Сигнал периметра».
- Новости с коротким видео исправлений коллизий и направлениями будущих улучшений.
- Каталог обновлений через GitHub Releases без поля адреса хозяина. Проверка пакетов игры по SHA-256, установка, откат и офлайн-запуск.
- Интерфейс игры «Графит» из 6.0.2 и исправления столкновений из 6.0.1 включены в выпуск. Сетевой протокол остаётся 6; всем участникам кооператива следует использовать одинаковую версию игры 6.0.3.

## Как установить

Windows: скачайте **Quarantine-Setup-6.0.3.exe**, полностью закройте игру и установите в прежнюю папку. Удалять старую установку не нужно. Этот установщик содержит новый лаунчер.

Mac Intel: **Quarantine-6.0.3-macOS-x64.dmg**. Mac Apple Silicon: **Quarantine-6.0.3-macOS-arm64.dmg**. Замените приложение в «Программах».

Настройки и сохранённые архивы остаются отдельно от установочных файлов. Node.js и Codex для запуска не нужны.

Выпуск также содержит **Quarantine-Game-6.0.3.qtg** для обновления самой игры, веб-архив и контрольные суммы. Пакет `.qtg` не меняет старую оболочку: для перехода на новое оформление нужен установщик.

Репозиторий закрытый: для скачивания на GitHub нужен аккаунт с доступом. Настройка доступа к обновлениям внутри лаунчера пока отложена. Встроенная игра и кооператив доступны без настройки этого доступа.
