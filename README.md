# Карантин —  версия 6.0

2D-стрелялка против мутантов: одиночная игра и кооператив на 2–4 бойцов, лаунчер для Windows и macOS со встроенным сервером и обновлениями. Все изменения версии 6.0, цены и правила — в [CHANGELOG-6.0.md](CHANGELOG-6.0.md).

## Windows-база

Оригинальные исходники Windows 6.0.0 сохранены без изменений в [windows-base](windows-base/README.md). Основной проект в корне репозитория основан на них: Windows-сборка доступна через `npm run build:win`, Mac-сборки — через команды ниже. `start-game.cmd`, Windows-иконки и настройки NSIS сохранены.

## macOS: Intel и Apple Silicon

Выпуски для Mac собираются отдельно: `Quarantine-6.0.0-macOS-x64.dmg` для Intel и `Quarantine-6.0.0-macOS-arm64.dmg` для M1/M2/M3/M4 и более новых Apple Silicon. Минимальная версия системы — macOS 12. Сборка arm64 запускается без Rosetta.

Откройте подходящий DMG, перетащите Quarantine в «Программы» и нажмите «ИГРАТЬ» в лаунчере. Установленная игра работает без Node.js. Сборки подписаны локально (ad hoc), без сертификата Developer ID и нотариализации Apple. Если macOS блокирует первый запуск, разрешите его в «Системные настройки → Защита и безопасность → Основные → Всё равно открыть» (на новых macOS: «Конфиденциальность и безопасность»).

В адаптации исправлена проверка абсолютных путей macOS и добавлено стандартное меню с Cmd+Q, копированием и вставкой. Чтобы уменьшить задержки на старых Intel Mac, кешируются фон и предметы, пропускается отрисовка объектов вне экрана, мини-карта обновляется 20 раз в секунду. Правила симуляции и сетевой протокол 6 сохранены. Возврат из старой версии к встроенной 6.0.0 сохраняет эти исправления.

На Mac для кооператива используйте локальную сеть или VPN, которая работает на всех компьютерах. Передайте друзьям адрес сервера и код комнаты. Radmin VPN относится к Windows; игра не требует именно его.

### Сборка из исходников

На Mac установите Node.js 24, затем:

```sh
npm ci
npm test
npm run build:mac:intel
npm run build:mac:silicon
```

`npm run build:mac` собирает обе архитектуры. Готовые DMG находятся в `release/`. Electron закреплён на 43.7.9, чтобы поддерживать macOS Monterey. Официальные версии Electron 44 и новее требуют macOS 13: https://www.electronjs.org/blog/electron-44-0

GitHub Actions использует отдельные Mac runners: `macos-15-intel` и `macos-15`. На каждом запускаются тесты, сборка и проверка запуска приложения своей архитектуры. Готовые файлы доступны в артефактах запуска `Build macOS`. Проверка типа процессора исключает проверку arm64 через Rosetta. Отдельный workflow `Build Windows` собирает EXE и проверяет его запуск на Windows. После изменений в `main` запускаются обе проверки; готовые установщики доступны в артефактах GitHub Actions.

## Как обновиться

Если уже установлен лаунчер 5.0, новый установщик не нужен:

1. Сохраните **Quarantine-Update-6.0.0.qtu** в «Загрузки» либо выберите «Добавить файл обновления» в лаунчере.
2. Нажмите «Обновить». Приложение проверит подпись, установит игру и перезапустится.
3. Друг указывает адрес вашего Radmin-сервера в лаунчере, например **http://26.x.x.x:5173**, и тоже нажимает «Обновить».

Кнопка «↻» в игре сообщает о доступной версии; проверка проходит каждые 30 секунд. Обновление завершает текущий матч. Управление и звук сохраняются, предыдущие версии доступны для отката. В комплекте лаунчера 6.0 есть версии 4.0.0, 5.0.0 и 6.0.0. Для одного матча всем нужна одинаковая версия.

При первой установке или переходе с приложения 4.0 используйте **release/Quarantine-Setup-6.0.0.exe**. Node.js и Codex установленной игре не нужны. Новое подтверждение закрытия окна приложения входит в установщик 6.0; игровые изменения и подтверждение выхода боковыми кнопками мыши доступны через пакет обновления.

Источник обновлений — сервер хозяина и подписанные файлы. Общий интернет-сервер не развёрнут. Хозяин раздаёт версии, пока его приложение и компьютер включены.

## Кооператив через Radmin VPN

1. Все входят в одну сеть Radmin VPN и запускают «Карантин».
2. Хозяин выбирает сложность и **2, 3 или 4 игрока**, создаёт комнату.
3. Передаёт друзьям адрес Radmin, показанный в меню, и код комнаты.
4. Друзья вводят этот адрес и код, нажимают «Войти».
5. Хозяин нажимает «Начать волны».

Собственный адрес обновляется автоматически; вручную введённый адрес друга сохраняется. Обычный порт — 5173, при занятости приложение выбирает свободный и показывает его. При запросе Windows разрешите игре доступ к сети. Компьютер и приложение хозяина должны оставаться включёнными; Codex можно закрыть.

## Новые правила боя

Стартовый пистолет имеет бесконечный запас и требует перезарядки. У остальных оружий отдельные боеприпасы, огнемёту нужно топливо. Гранаты ранят владельца и союзников, флешка оглушает. В начале каждой волны каждый игрок получает 100 монет. Между волнами передышка 5 секунд. Тайм-ауты по две минуты без ограничения; продолжить раньше можно голосованием большинства.

Погибший оставляет гроб, который блокирует мутантов, и возрождается у него на следующей волне с 70 HP. До возрождения можно наблюдать союзников. Над врагами и постройками отображаются численные HP.

Строительство требует молотка и предмета в рюкзаке: первый клик показывает проект, второй ставит его. У досок, дверей, шипов и колючей ограды пять уровней, от дерева до композита. Нажмите на ближайшую турель для покупки её улучшений и брони.

| Турель | Цена | HP | Лимит на отряд |
| --- | ---: | ---: | ---: |
| Страж | 2600 | 2200 | 10 |
| Бастион, два ствола | 6200 | 5000 | 5 |
| Пекло, огнемёт | 3900 | 3500 | 5 |

Мутанты атакуют турели; обычный удар ослаблен, роботы и лава опаснее. Боссы получают от основного огня турелей 20% урона. Прыжки и рывки боссов учитывают движение героя.

Случайно через 2–8 минут активных волн наступает ночь на 3 минуты активного боя. Ночью приходят быстрые и сильные мутанты и обычные некроманты. Фонарик не разряжается; ПНВ работает 180 секунд только во включённом состоянии. Новые адские мутанты поджигают, плюются лавой, оставляют лавовые следы или ставят четыре вызывающих врагов тотема по краям карты. Обычные появления врагов происходят рядом с краями; коконы и другие локальные способности сохраняются.

## Разработка и проверки

- `npm ci` — зависимости.
- `npm start` — браузерный сервер http://localhost:5173.
- `npm run desktop` — лаунчер со встроенным сервером.
- `npm test` — симуляция, сетевые клиенты и подписанные обновления.
- `npm run desktop:smoke` — проверка запуска приложения.
- `electron . --smoke-update-cycle` — изолированная проверка отката 6→5 и обновления 5→6 с перезапусками.
- `npm run pack:update` — подписанный пакет текущей версии.
- `npm run build:win` — Windows-установщик.
- `npm run build:mac` — DMG для Intel и Apple Silicon.
- `npm run verify:mac` — подпись, архитектура и запуск собранного приложения на текущем Mac.

Для нового выпуска измените версию package.json, а при несовместимости сетевой протокол в content.js. Выполните тесты и `pack:update`, положите новый пакет в assets/update.qtu перед сборкой установщика. Закрытый ключ хранится вне проекта в **%USERPROFILE%/.quarantine-dev/signing-key.pem**; публичный ключ включён в приложение. Пакет обновляет игру и её сервер. Замена Electron и самого лаунчера требует сборки приложения.
