# Новый лаунчер Карантина

Включает игру 6.0.5 с интерфейсом «Графит» и новое оформление лаунчера: обзор, версии игры, новости с видео о коллизиях, настройки памяти и звука, постоянный архив новостей крупных версий, звуки тумблеров, сохранение настроек с выходом и четыре оригинальных трека с автоматической сменой.

## Установка

- Windows: скачайте **Quarantine-Launcher-Setup.exe**, полностью закройте игру и установите в прежнюю папку. Удалять предыдущую установку не нужно.
- Mac Intel: **Quarantine-Launcher-macOS-x64.dmg**.
- Mac Apple Silicon: **Quarantine-Launcher-macOS-arm64.dmg**.

Настройки и сохранённые архивы находятся отдельно от установочных файлов. Node.js и Codex для запуска не нужны. Контрольные суммы установщиков — в **SHA256-launcher.txt**.

## Почему старый лаунчер не изменился после обновления игры

Обновления игры содержат игровые файлы, а оформление и настройки лаунчера входят в приложение. Чтобы перейти со старой оболочки с полем адреса хозяина, один раз установите этот новый лаунчер.

Этот выпуск остаётся постоянной страницей скачивания лаунчера. Будущие версии игры публикуются отдельными пакетами `.qtg`, которые новый лаунчер умеет проверять и устанавливать через GitHub Releases.

Репозиторий сейчас закрытый: для скачивания установщика на GitHub нужен аккаунт с доступом. Настройка доступа к обновлениям внутри приложения отложена; без неё загрузка новых версий из GitHub недоступна. Встроенная игра 6.0.5 и кооператив работают, установленную игру можно запускать офлайн.
